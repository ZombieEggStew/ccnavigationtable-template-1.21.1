# 板式监视器

![板式监视器](../img/monitor_slab.png)

板式监视器（Monitor Slab）是一个**台阶状**的监视器方块：表面是一个 **14×14** 的棋盘式插槽面板，可以像监视器一样安装按钮、开关、旋钮、屏幕等模块，并通过 CC:T 计算机用 Lua 自由控制它们。

与[监视器](monitor.md)相比，它形态扁平（半格台阶），适合铺在地面、贴墙或贴天花板作为信息面板。它复用监视器的频道与外设系统，但配置更简单（只设置频道）。

## 三种附着形态与朝向

板式监视器可以附着在三种面上：

| 形态 | 附着位置 | 面板方向 |
|---|---|---|
| 地板（FLOOR） | 方块顶面 | 面板朝上 |
| 墙面（WALL） | 方块侧面 | 面板朝外 |
| 天花板（CEILING） | 方块底面 | 面板朝下 |

!!! warning "放置时注意朝向（地板与天花板各有 4 种朝向）"
    地板与天花板变体都各有 **4 种朝向**（FACING），跟随玩家放置时的水平朝向：**地板 = 玩家朝向的反方向，天花板 = 玩家朝向**；墙面 = 点击的面。
    表面模块 / 屏幕内容的**显示方向**会随这个朝向改变——放置时请留意朝向，确保内容朝向你需要的方向。

## 获取 Monitor Slab 外设

CC:T 外设类型名是 `"ccpe:monitor_slab"`，获取方式与监视器相同（共用同一全局频道系统）：

```lua
-- 方式 A：通过频道获取（推荐，跨距离）
local pe = require("ccpe.pe")
local slab = pe.getPeripheral(3)   -- 3 是板式监视器的全局频道号

-- 方式 B：计算机紧贴放置时直接 wrap
local slab = peripheral.wrap("right")
-- 或
local slab = peripheral.find("ccpe:monitor_slab")
```

## 操作说明

- **放置模块**：手持模块物品（按钮 / 开关 / 旋钮 / 屏幕）右键面板放置；屏幕为**两点放置**（右键两个空格子，形成一个矩形区域）。
- **配置频道**：手持扳手 **右键**（或空手 **蹲下右键**）打开配置界面，设置**全局频道号**（与监视器 / 外设扩展器共用频道系统）。
- **配置模块**：手持扳手右键模块 / 屏幕 → 打开模块配置界面。
- **拆卸模块**：手持扳手 **蹲下右键** 模块 / 屏幕 → 拆下该模块。
- **整块拆除**：扳手蹲下右键面板空白处 → 整块拆除，返回**普通板式监视器物品（不保留任何数据）**；表面已装内容时会被阻止（提示先拆除模块）。
- **直接破坏**：掉落普通板式监视器 + 表面模块 / 屏幕物品（模块与方块分离）。

## Lua 接口

与[监视器](monitor.md)共用同一套接口（`MonitorGridHost`）：`getCellModule(x, y)` / `getModule(id)` 查询模块与屏幕实例，`playNiceSound()` / `playSound(name)` 播放音效。

模块实例（按钮 / 开关 / 旋钮 / 屏幕）的通用方法与详细 API 见 [监视器概述](overview.md) 的「模块实例通用方法」与 [按钮模块](button.md) / [开关模块](switch.md) / [旋钮模块](knob.md) / [屏幕模块](screen.md)。

屏幕的文本 / 图形 API 与普通监视器的屏幕模块完全一致（见 [屏幕模块](screen.md)）；内容方向跟随放置朝向，从面板正面看可读。
