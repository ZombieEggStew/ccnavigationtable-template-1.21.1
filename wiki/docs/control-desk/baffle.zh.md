# 挡板

![挡板](../img/baffle.png)

挡板不是独立控件，而是控制台的**形态转换**：它把[控制台](overview.zh.md)变成**3/4 楼梯**形状。

**安装**：手持 **Create 黄铜外壳**（`create:brass_casing`）右键已放置的控制台。控制台模型切换为楼梯形态，选择框随新形状变化。

## 效果

- 北侧区域（`z0..8`）竖起全高立墙，南侧保留低矮桌面 —— 控制台变为 3/4 块楼梯。
- **桌顶网格模块不受影响**：[操纵杆 2](joystick_2.zh.md)、[油门杆](throttle.zh.md)、[油门杆 2](throttle_2.zh.md) 和[监视器 2](monitor_2.zh.md) 仍可放置在后侧桌面，与挡板共存。

## 互斥

- 挡板与**脚踏板**、**操纵杆**（安装在立墙覆盖的北侧区域）以及[拓展坞](dock.zh.md)（同为形态转换）冲突。必须先拆除踏板/操纵杆/拓展坞，才能安装挡板。
- 已装拓展坞的控制台不能再装挡板，反之亦然。

## 拆除

手持 Create 扳手**蹲下 + 右键**控制台北侧全高立墙。控制台恢复 base 形态，掉落一个黄铜外壳。

!!! tip "挡板 vs 拓展坞"
    拓展坞扩展桌面（和放置网格），挡板则是竖立一面墙。需要更多桌顶网格空间用[拓展坞](dock.zh.md)，需要背板/护栏用挡板。
