# 拓展坞

![拓展坞](../img/dock_extension.png)

拓展坞不是独立控件，而是控制台的**形态转换**：它把[控制台](overview.zh.md)变成整块桌面的 台阶 形态。

**安装**：手持 [**控制台**](overview.zh.md)（放置控制台用的那个方块）右键已放置的控制台**侧面**。桌顶棋盘网格从 6×14 扩展为 **14×14**。

## 效果

- 桌面向前延伸（`z0..8`），控制台变为完整的 16×8×16 slab。
- **桌顶网格扩展为 14×14**（`x1..15 / z1..15`）：[油门杆](throttle.zh.md)、[油门杆 2](throttle_2.zh.md) 和[监视器 2](monitor_2.zh.md) 可以在新的边界范围内自由选择 z 位置，[操纵杆 2](joystick_2.zh.md) 的可放置区域也大幅增加。
- 控制台的其余功能全部保留（频道、坐垫操作模式、CC 外设）—— 只改变外形。

## 互斥

- 拓展坞与**脚踏板**、**操纵杆**冲突（它们安装在拓展坞覆盖的北侧空区）。必须先装拓展坞再装踏板/操纵杆；想后装它们需先拆拓展坞。
- 拓展坞与[挡板](baffle.zh.md)**互斥**（两者都是形态转换）—— 同一时间只能激活一种形态。

## 拆除

手持 Create 扳手**蹲下 + 右键**控制台北侧区域。

!!! warning "请先拆除拓展坞上方的模块"
    放置在**拓展坞新增区域**（普通 6×14 网格以北、由拓展坞扩展出来的前几行）上的桌顶模块，必须**先拆除**才能拆拓展坞 —— 否则这些模块会悬空在桌面边缘外。先移动或拆除这些模块，再拆拓展坞。拆除后控制台恢复 base 形态，并掉落一个控制台方块物品。
