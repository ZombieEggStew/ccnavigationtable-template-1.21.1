# 冷却气道

![cooling_duct](../img/cooling_duct.png)

**冷却气道**（`ccpe:cooling_air_duct`）是[引擎系统](overview.zh.md)的纯散热模块。贴附在引擎核心上，为冷却模型贡献散热分量（`K_DUCT`）——同时也是**冷却风门**（`setCooling`）的载体。

## 放置

- 贴附在引擎核心任意面（6 面 × 每面 2 旋转 = 12 个 blockstate）。
- 无方块实体——纯静态方块，所有冷却逻辑都在引擎 controller 里。

## 作用

- **散热鳍片**：每个气道为引擎牛顿冷却贡献固定散热分量（`K_DUCT = 0.05`/个），装得越多冷得越快。
- **冷却风门**：`setCooling(0..1)`（默认 1.0 = 全开）只缩放风道散热分量——关小风门 = 减少风道散热（真实 cowl flap「保热」行为）。**不能**超过已装风道的上限：想更冷就多装风道。
- **纯散热模块**：不门控经济系数、混合比或油耗。

!!! note "`setCooling` / `setMixture` 均纯存值无门控"
    `setCooling` 与 `setMixture` 任何时刻都接受（无门控）。风门值只在**装了冷却气道**时被消费（`K_DUCT` 分量）；混合比值只被流体引擎消费。蒸汽引擎上两者都只存值、不生效。

## Goggle 显示

戴 goggles 悬停气道：

```
发动机状态
温度：XX.X°C
冷却：80%
```

**冷却**行 = 风门百分比（`coolingStrength`，即 `setCooling` 值）——低于 100% 表示风门已关小保热。
