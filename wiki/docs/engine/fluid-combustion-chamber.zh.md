# 流体燃烧室

![fluid_combustion_chamber](../img/fluid_combustion_chamber.png)

**流体燃烧室**（`ccpe:fluid_combustion_chamber`）贴附在[引擎核心](engine-core.zh.md)上，燃烧 **其他模组 流体燃料**——每室贡献 **8192 SU**（× 燃料 stress 倍率）。这是引擎系统的「经济管理」半边：油耗与温度由**应力网络负载**驱动，再由**混合比**、经济区、过冷惩罚与冷却气道风门微调。

## 放置

- 右键将燃烧室对准引擎核心的任意面。有放置虚影预览贴附位置。
- 可以在核心排周围贴任意多个燃烧室，每个燃烧室都是一个独立输入模块。
- **流体室与蒸汽室在同一台引擎上互斥**——不能混装（放置被拦截，controller 按多数派仲裁）。

## 燃料

- 燃料来自 **datapack**：`data/<命名空间>/engine_fuel/*.json`（`/reload` 热加载）。不需要特定燃料源方块——引擎通过 capability 从模块邻居任意流体储罐 drain（严格零内部流体缓存，[快速装填流体储罐](fuel.zh.md#quick-fill-fluid-tank) 即可）。

### 支持的燃料

| 柴油 Diesel | Create: Diesel Generators（`createdieselgenerators:diesel`） | 1.0 | ×1.25 | ×1.25 |
| 生物柴油 Biodiesel | Create: Diesel Generators（`createdieselgenerators:biodiesel`） | 1.0 | ×1.0 | ×1.0 |
| 汽油 Gasoline | Create: Diesel Generators（`createdieselgenerators:gasoline`） | 1.0 | ×1.0 | ×1.0 |
| 乙醇 Ethanol | Create: Diesel Generators（`createdieselgenerators:ethanol`） | 1.0 | ×0.5 | ×0.5 |
| 植物油 Plant Oil | Create: Diesel Generators（`createdieselgenerators:plant_oil`） | 1.0 | ×0.5 | ×0.5 |
| 珊瑚 Coral | Create Propulsion: Simulated（`createpropulsion:coral`） | 1.0 | ×1.25 | ×1.25 |

各倍率的意义：

- **`stress`** 缩放每室 **8192 SU** 基础出力——柴油/珊瑚每室 **10240 SU**，乙醇/植物油只有 **4096 SU**。
- **`heat`** 缩放进入温度模型的发热（见[温度与冷却模型](temperature.zh.md)）——柴油/珊瑚更热，乙醇/植物油更凉。
- **`consumption`** 是每室烧速（mb/s）——松节油烧 **1.5 mb/s**（同功率下耗油更快），其余均 1.0。
- **单燃料制**：引擎按源列表查找顺序选第一个可用燃料——周围有多个罐时，扫描顺序决定烧哪种。
- 以上只是自带条目——引擎接受任意 datapack 的 `engine_fuel/*.json`，其他模组的流体也可照此添加。

## 出力与消耗模型

- **应力容量** = 运行室数 × 8192 × 燃料 `stress`——**恒定，与油门无关**（油门只改转速）。
- **油耗** = 运行室数 × 燃料 `consumption` × **燃烧强度** × 杆值 × 经济系数 × 过冷惩罚（见下）。
- **发热** = 运行室数 × **发热负载** × 燃料 `heat` × `BASE_HEAT_FLUID(30)` × `heatFactor(实际混合比)`。
- 其中 **燃烧强度 = max(上一 tick 负载, 怠速下限 0.2)**（油门 0 时 = 0），**发热负载 = max(负载, 0.2)**；
  `杆值 / 经济系数 / 过冷惩罚` **只乘油耗，绝不乘发热**（否则「经济省油不省热」「富油花油买冷」两条设计张力会塌）。

## 负载

**负载** = 引擎所在应力网络的「已用应力 / 可提供容量」。它是这套引擎的「功率表」：

- **怎么变**：挂更多机器（应力影响累加）、或把转速拉高（每台机器的应力 ∝ 转速）→ 负载上升。所以**推油门与加机器在温度表上等价**。
- **驱动什么**：油耗与发热都 ∝ 负载。想省油 / 降温 → 减机器或降转速；想热起来 → 加机器或提转速。
- **怠速下限**：负载为 0 时仍按 **20%** 燃烧保温（对应真实内燃机怠速油耗）。核心 goggle 的「负载」行显示的是**实际利用率（0%）**，下限只进计算。
- **过载**：负载超过可提供容量 → 钳在 100%，goggle 顶部红字「网络过载」，引擎照常满负载燃烧（不停机）。

海平面静止、4 流体室 + 2 冷却气道的示例平衡温度（推导见[温度与冷却模型](temperature.zh.md)）：

| 负载 | 平衡温度 | 说明 |
|---|---|---|
| 0%（怠速，发热按 20%） | ≈83°C | 怠速保温，略低于工作温度 |
| 25% | ≈99°C | 刚跨过 100°C 工作线 |
| 43% | ≈156°C | **经济带**（145~165） |
| 63% | ≈219°C | **过热阈值** 220°C |
| 100% | 钳 264°C | 静止时满负载必然过热停机 |

**结论**：满负载能不能维持，取决于散热——飞行速度（冲压 ×2）、冷却气道数量与风门开度、海拔。这与真实发动机的「最大持续功率 < 最大功率」完全一致。

## 混合比

`setMixture(0.6~1.4)`（默认 1.0）只影响**给定负载下的油耗与发热**——不影响应力/转速：

- **双侧统一线性热因子**：`heatFactor = 1 − (m−1)`（即 `2 − m`），斜率 −1，无凸曲线/无下限钳制。
- **拉稀（< 1.0）** = 省油，但更热。热因子线性上升：`m=0.8 → ×1.20`。
- **富油（> 1.0）** = 花油买冷。热因子线性下降：`m=1.2 → ×0.80`、`m=1.4 → ×0.60`（无下限封顶）。
- **高度自动浓稀**：化油器按进气体积配油——越高空气越稀天然变浓（最高 ×1.25），海平面以下高气压天然变稀（最低 ×0.75）——**实际混合比 = 杆 × autoRichness(气压)**，`autoRichness = 1 + 0.45×(1−气压)` 钳制 [0.75, 1.25]。自动浓/稀只影响发热（满自动富油发热 ×0.75），**绝不费油**。Y≈260 时自动富油 ≈×1.25，所以把杆拉到 ≈0.8 时实际混合比 ≈1.0（海拔补偿，吃经济）。

## 经济系数

**经济系数**是双因素 AND 门控 + 时间解锁的折扣（0.75~1.0）：

- 需要 **`|T − 155°C| ≤ 10` 且 `0.8 ≤ 实际混合比 ≤ 1.1`**（平底窗口）。
- 持续达标 **15 秒**渐入 **×0.75**（省 25% 油）；离开窗口 **6 秒**流失。关键是**持续保持**——快速掠过不奖励。
- 混合比不对 → **无奖励无惩罚**。
- 经济系数只乘消耗，**绝不反哺发热**。

## 温度与冷却

> 完整的发热/散热公式、高度→温度与高度→气压曲线见 [温度与冷却模型](temperature.zh.md)。

- **牛顿冷却模型**：发热 − 散热（环境 + 核心 + 冷却气道，按速度冲压与高度气压缩放），对热容积分。
- **环境温度**按高度变化（主世界海平面 20°C → 云层 0°C → 世界顶 −40°C）；**地狱全高度恒定 155°C**、**末地全高度恒定 0°C**。
- **冲压冷却**：10 m/s 以下 ×1.0，线性爬升到 **30 m/s 时 ×2.0**——飞得快免费降温。
- **过冷惩罚**（`cold`）：低于 100°C 油耗上升：`cold = 1 + max(0, 100−T)/100`（20°C 时 ≈×1.8）。冷机时负载低、绝对油耗本来就小，所以「冷机损失轻」；把机器 / 转速带起来，温度进入经济带后惩罚自然消失。
- **过热**：T ≥ **220°C** 硬停（不烧油）；T ≤ **200°C** 滞回恢复。过热是流体引擎除油门 0/缺燃料外唯一的停机原因。

## 状态显示

戴 goggles 悬停燃烧室（全量引擎状态）：

```
发动机状态
状态：停机 / 过冷 / 正常 / 高效 / 即将过热 / 过热
温度：XX.X°C
油耗：×0.60
发热系数：×1.08
```

!!! note "油门与负载不在这里显示"
    两者只在[引擎核心](engine-core.zh.md)的 goggle 显示——本室 tooltip 只关心自己的状态、温度与油耗。

| 温度区间 | 状态 | 颜色 |
|---|---|---|
| —（!running） | 停机（油门 0 / 缺燃料 / 缺水） | 灰 |
| < ~97°C | 过冷（油耗惩罚中） | 蓝 |
| 97 ~ 145°C | 正常 | 绿 |
| 145 ~ 165°C | **高效**（经济带 \|T−155\|≤10） | 青 |
| 165 ~ 200°C | 正常 | 绿 |
| 200 ~ <220°C | 即将过热 | 金 |
| ≥ 220°C | 过热停机（200°C 解锁） | 红 |

**油耗**行 = 每单位负载的油耗系数 = 杆值 × 经济 × 过冷（实际烧速还要乘负载与燃烧强度）；**发热系数** = `heatFactor(杆 × 高空自动富油)`。温度档位是「负载 + 散热」共同作用的结果，不再由油门直接决定。

!!! note "温度阈值由引擎设计固定"
    155°C 经济目标 / 100°C 过冷阈值 / 220°C 过热——全部是引擎常量，不随燃料 / 油门 / 负载变化（真实引擎设计点 / 节温器恒定）。真正决定你落在哪一档的是「负载 vs 散热」的平衡。
