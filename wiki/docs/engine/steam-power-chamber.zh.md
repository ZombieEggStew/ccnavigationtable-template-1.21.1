# 蒸汽动力室

![steam_power_chamber](../img/steam_power_chamber.png)

**蒸汽动力室**（`ccpe:steam_power_chamber`）贴附在[引擎核心](engine-core.zh.md)上，用**水 + 燃料**发电——每室贡献 **4096 SU**。这是引擎系统的「简单稳定」半边：闭式锅炉自调节、真实蒸汽车节流阀消耗模型、余热运转。

## 放置

- 右键将蒸汽室对准引擎核心的任意面（贴附在点击面），有放置虚影预览。
- **蒸汽室与流体室在同一台引擎上互斥**——不能混装。

## 工作流程

1. **燃料与水** — 在引擎附近放[快速装填燃料箱](fuel.zh.md#quick-fill-fuel-vault)（固体燃料）和/或装有可燃桶燃料（如熔岩）的流体罐，外加一个水源罐。controller 通过 capability 自动从邻居存储抽取（零内部缓存）。
2. **点火** — 有水有燃料，锅炉开始燃烧。
3. **暖机** — 低于 100°C 时只烧燃料**不输出应力**（`isWarmingUp()`）。
4. **出力** — T≥100°C 且油门>0，每室 **4096 SU** 输出应力。

## 闭式锅炉——永不过热

- 锅炉自调节，钉在 **155°C**（饱和温度）——与气压、环境、冲压无关，蒸汽引擎**高度免疫**。
- **无过热**、无混合比杆、无经济区、无需冷却气道。
- 缺水 → 停烧（防干烧）→ 牛顿冷却。

## 燃料

蒸汽引擎只用**原版燃料形式的燃料**（无需 datapack）：

- **流体燃料优先**：桶物品原版熔炉燃烧时长 > 0（如熔岩桶 = 20000 tick）。引擎 drain 流体并按燃烧时长换算。
- **固体燃料兜底**：流体燃料不可用时，从邻居快速装填燃料箱抽取原版 `burnTime > 0` 的固体物品（如煤炭 = 1600 tick）。
- **并行燃烧**：N 个蒸汽室同时烧 N 个燃料（每室 1 个，同燃同熄）。一次抽 **N×K 个**（K = 配置批次倍数，默认 1.0）；当前箱不足 N×K → 切下一箱，整组断供不拆零。
- **水**：1mb/s/室 × 油门，从邻居水源罐批量抽取。

## 真实蒸汽车油门——消耗 ∝ 油门

- 燃料、水、流体全部**随油门缩放**：25% 油门 = 1/4 蒸汽流量 = **燃料耐用 4 倍**。
- 油门 **0 = 停机**——不抽不烧。
- Goggle 燃料行显示**墙钟剩余时间**：`burnTicks / (油门 × 20)`（如「煤炭 x3 (1m 20s)」）——倒计时与真实时间同步、低油门拉长；油门 0 不显示倒计时（停机）。

## 余热运转

燃料耗尽后，只要锅炉还热就继续发电：

- 运行条件 = **油门开启 且 T≥100°C 且水可用**（锅炉热起来后不再要求有燃料）。
- 地狱维度环境温度固定155°C，只需要水就能持续工作。
- 燃料耗尽但 T≥100°C 且水未断供 → 仍工作。
- 只有**缺水**（防干烧）或冷却到 **100°C** 以下才停机。
- 燃烧倒计时独立于燃料源：拆掉燃料箱后，已抽出的燃料继续烧完为止。

## Goggle 显示

戴 goggles 悬停蒸汽室：

```
发动机状态
状态：正常 / 暖机中 / 停机
温度：XX.X°C
油门：50%
燃料：熔岩 / 煤炭 x3 (1m 20s) / 无
```

- **状态** — 正常 / 暖机中（金）/ 停机。
- **燃料** — 流体燃料只显示名称（绿）；固体燃料显示「名称 xN」（N = 蒸汽室个数，并行燃烧）+ 英文括号墙钟时间；无储备显示红色「无」。
