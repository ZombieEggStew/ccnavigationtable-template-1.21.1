# 引擎核心

![engine_core](../img/engine_core.png)

**引擎核心**（`ccpe:engine_core`）是引擎系统的骨架——一个 Create 动力源方块，可组网成多方块结构。排成一排的核心会合并成**一条引擎**（1×1×N，最多 21 节），整条共享运行状态、温度与油门；只有 **controller**（排头/排尾的一端）输出应力与决策。

## 组网与放置

- 先放第一块核心，然后**拿引擎核心物品右键已有引擎**沿轴向延伸放置（Create `PoleHelper` 放置助手），核心自动合并成一条多方块引擎。
- 引擎会持久化：区块重载后核心按存档位置自动重组（`Uninitialized` / `LastKnownPos` NBT，Create 蓝图同样支持）。
- 延长引擎时**运行状态会被继承**——在 controller 端延长时温度/油门/混合比/经济进度等不重置。
- **controller**：位于排一端的方块。只有 controller 每 tick 工作、发电并持有 Lua 外设；非 controller 的 `getGeneratedSpeed()` 恒 0，但**任意核心节**都可以从 Lua 读取/写入引擎（外设委托给 controller）。

## 出力模型：应力固定、油门定转速、负载定油耗

- **应力容量恒定** = 流体室数 × 8192 SU × 燃料 `stress` 倍率 + 蒸汽室数 × 4096 SU——**与油门无关**。
- **转速 = 油门 × 256 rpm**（0~256 线性）。默认油门：**0.25（64rpm）**。**油门只决定转速**。
- **负载** = 已用应力 / 可提供容量（0~1）：下游接的机器越多、转速越高，负载越大。**油耗与发热 ∝ 负载**；空载按怠速下限（20%）燃烧保温。
- **防作弊**：容量绑的是引擎**自身生成转速**而不是网络转速，外部转速控制器 / 电子变速箱只能抬高下游应力需求（→ 过载），**无法放大容量**。
- **过载不停机**——对齐 Create 发电机：超过容量的部分只是 goggle 顶部红字「网络过载」，引擎照常满负载燃烧。

## 运行条件

引擎仅在「运行」时输出应力：

- **≥ 1 个运行燃烧室**（有燃料在烧），
- **油门 > 0**（油门 0 = 停机，不烧油），
- **未过热**（仅流体引擎：T≥220°C 硬停，T≤200°C 滞回恢复），
- **蒸汽引擎**：T≥100°C 且水可用（<100°C 暖机只烧不发电），
- **过载不停机**——对齐 Create 发电机：照常运行烧油，goggle 顶部红字「网络过载」提示。
- 以上条件只看引擎自身状态；**负载不参与运行判定**，它只决定「烧多快、多热」。
- 蒸汽引擎额外要求**正在烧燃料**：温度 155°C 的维持本身要烧燃料，燃料烧完就开始降温（见[蒸汽动力室](steam-power-chamber.zh.md)）。

## Goggle 显示

戴 Create goggles 悬停任意核心节（tooltip 委托给 controller）：

```
发动机状态
温度：XX.X°C
总应力输出：32768 SU
油门：25.0%
目前转速：64 RPM
负载：0%
连接的模块：
- 流体燃烧室 x4
- 冷却气道 x2
```

- **总应力输出** = 引擎可提供的总应力（服务端同步，**恒定、与油门无关**）。
- **油门** = `setThrottle` 的当前值；**目前转速** = 油门 × 256。
- **负载** = 实际网络利用率（空载 0%，满载 100%，≥90% 标红）；它才是油耗与温度的驱动量。
- 模块清单显示贴附的燃烧室 / 气道。

!!! note "油门与负载只在引擎核心显示"
    各模块（流体燃烧室 / 蒸汽动力室 / 冷却气道）的 goggle 不再重复油门与负载，只看自己的状态、温度与燃料。

## Lua 控制

引擎只能从 Lua 控制（无红石）。包裹**任意核心节**为 CC:T 外设——外设挂在 controller 上，非 controller 节委托给它：

```lua
local e = peripheral.wrap("front")
print(e.getTemperature())  -- 温度 °C
e.setThrottle(0.5)         -- 50% 油门 = 128rpm（应力容量不变）
print(e.getLoad())         -- 负载 0..1：网络的已用应力 / 可提供容量
```

完整方法见 [Lua API 页面](lua-api.zh.md)。
