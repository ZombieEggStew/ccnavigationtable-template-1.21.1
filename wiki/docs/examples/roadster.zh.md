## 使用方法：
右键计算机（黄色方块），点击左上角第二个按钮（或者按住Ctrl+T1秒以上）关闭当前程序，然后输入以下指令

```
autopilot track axis=z:-107.5
```

即可开启自动驾驶模式

控制程序位置：\New World (2)\computercraft\computer\3
