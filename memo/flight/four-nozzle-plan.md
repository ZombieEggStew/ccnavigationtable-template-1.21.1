## 1. 坐标系与三个必须记住的约束

- 机体：**X 左右、Y 上下、Z 前后（机头 −Z）**；`getForcePoint()` 的 `x/y/z` 就是力臂 `r_i`（原点=质心）。
- **约束 1**：`getForcePoint()` / `getSensors()` 是 `mainThread = true` ⇒ 每次调用占一个写块（约 1 tick）。
  **只在初始化读一遍并缓存**，绝不放进 20 Hz 控制环。
- **约束 2**：物理体原点 = 质心；**在机体上加/删方块后**原点会漂，旧 `r_i` 作废 ⇒ 改装后重跑 P0。
- **约束 3**：`setDirection(+x)` 的受力符号**不能从几何推**（两发实测与推导反号，黑名单 #14）。
  四台同向安装 ⇒ 全机一套映射，但**仍要一次实测**符号后才准开横向/偏航环。

## 2. 四发控制分配（本计划的核心，全部由 `r_i` 算，不手填）

记 `F_i = u_i·K_NOZ·p`（竖直、朝上），`τ = Σ r_i × F_i`：

```
τ_x = −Σ z_i·F_i        （俯仰：前后）
τ_z =  Σ x_i·F_i        （滚转：左右）
τ_y =  Σ (z_i·F_x,i − x_i·F_z,i)   （偏航：只能来自锥角）
```

| 通道 | 手段 | 分配公式 | 净侧效应 |
|---|---|---|---|
| 总距 `F_z` | 四台同增 | `u_i = u0` | — |
| 俯仰 `τ_x` | **前后推力差** | `u_i += α·(−z_i)/Σz²`，`α = Δτ_x/(K·p)` | 零横向力 |
| 滚转 `τ_z` | **左右推力差** | `u_i += β·(+x_i)/Σx²`，`β = Δτ_z/(K·p)` | 零横向力 |
| 偏航 `τ_y` | **四台切向锥角** | 方向 `t_i = (z_i, 0, −x_i)/L_i`，幅值 `F_t,i = γ·L_i` ⇒ `τ_y = γ·ΣL²` | `Σ F_t,i·t_i = γ(Σz_i, −Σx_i) = 0`（矩形居中时） |
| 横移 `F_x/F_z` | **四台共模锥角** | 四台同向 `setDirection`，幅值按 `F_h = F_i·sinθ` | `τ = (Σr_i)×F = 0`（矩形居中时） |
| 垂直损失 | 锥角 `θ` | `F_z` 乘 `cosθ`（15° 只掉 3.4%，可忽略，但高度环会看见） | — |

**与两发的本质区别**：

1. **滚转改由推力差直接控制**（两发被迫用同向锥角），锥角空出来专管偏航 + 平移；
2. 四台推力 = **4 输入 / 3 方程**（`F_z, τ_x, τ_z`）⇒ 多一个自由度，**常值偏置（质心偏、风扇效率差）可以配平**：
   等 u 悬停量出残余 `τ_x, τ_z` 后，`δu` 取 4×3 矩阵 `[1; −z_i; x_i]` 的最小范数解；
   两发只能给一个配平比 `r*`，这是四发真正多出来的东西；
3. 四台两两对称 ⇒ 共模锥角的力矩自抵消、切向锥角的横向力自抵消，**平移与转动解耦**（前提：P0 验矩形居中）。

**写入预算**：`4×setThrustScale + 4×setDirection` 放进**同一个** `parallel.waitForAll` = **1 tick**
（constants 黑名单 #21：块数= tick 数，块内条数不收费）。拆成两块才是 2 tick。

三个实现注意：

1. **锥角通道要按每台的 `u_i` 归一化**：`F_h,i = u_i·K·p·sinθ_i` ⇒ `θ_i = F_h,i/(u_i·K·p)`。
   做俯仰/滚转差动时四台 `u` 不同，若四台用同一个锥角，横向/偏航会带出额外力矩。
2. **垂直损失** `ΣF_i·cosθ` 进高度环前馈（15° 掉 3.4%）；横移加速时它会变成"掉高"。
3. `setDirection` 是 `-1..1` 的圆形摇杆（长度=锥角/15°）；四台同向安装 ⇒ 全机一套 body↔局部映射，
   但**符号必须 P4 实测一次**再用（黑名单 #22）。

## 3. 测量计划（一步一上机，P0 本轮）

| 阶段 | 程序 | 内容 | 通过判据 |
|---|---|---|---|
| **P0** | **`m4probe geom` + `static`** | 只读：4 台 `getForcePoint`、质量、气压、AIC、矩形校验、分配系数 | 4 台都有 `r`；`y` 共面散差 <0.05；形心 `abs(x),abs(z)` <0.15；`id` 里 AIC 在 |
| P1 | `m4cal`（未写） | 抬到 ≥2 m，四台等 u 悬停 1.5 s，量残余 `wx/wz`；最小范数 `δu` 配平；顺带总距标定 | 配平后 2 s 内 `abs(wx),abs(wz) <0.02 rad/s` |
| P2 | `m4cal` | 俯仰（前/后对）与滚转（左/右对）**双峰**脉冲，量 `α/单位` | 正负段对称、`α` 信号 ≫ 基线 |
| P3 | `m4cal` | 四台**切向**锥角双峰，量偏航增益 | `τ_y` 方向与 `ΣL²` 一致 |
| P4 | `m4cal` | **共模锥角**双峰，先验符号；量横向力/加速度 | 净滚转/俯仰 <噪声；横向力随锥角线性 |
