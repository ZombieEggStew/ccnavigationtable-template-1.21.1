## §3 推导（只写能站住的）

### 3.1 恒值偏置的量级

`α_x ≈ 0.05 rad/s²`（LIFT 段 wx 0→0.075 用 1.45 s；HOLD 段 +0.032）。等价的构造误差：

```
若来自横向/纵向重心偏移 δz：  τ = δz·T_total,  δz = α·I / T_total
  取 I≈10 kg·m²、T_total=124 pN ⇒ δz ≈ 0.05·10/124 ≈ 4 mm
若来自两台推力差 ΔT：        τ = b·ΔT ⇒ ΔT ≈ 0.25 pN ≈ T 的 0.5%
```

⇒ **毫米/千分之几级别的不对称就足够**。memo 的"两发稳只能来自绝对对称"这条，量级上被证实。

### 3.2 α/D 与 b 的矛盾（未解决）

刚性预测 `α/D = 2·b·K·p/I`。b=2、K·p=517、I≈10 ⇒ **≈200 rad/s²/单位 D**；实测 `|α/D|≈11`（且是 `wz` 轴）。
差 ~10 倍。可能：① 有效前後力臂只有 ~0.2 格；② 差动没有真的产生 `2D·K·p` 的推力差；
③ 本轮 `α/D` 本身就是废数（`wx` 基线 0.05 与脉冲同量级）。
**在锥角映射测试（用 `τ = r × F` 直接测力臂）之前，不得采用任何 α/D 数值。**

### 3.3 姿态门控为什么在 61° 触发

`up = 1 − 2(qx² + qz²)` = 机体"上"向量与世界"上"的点积；`up=0.48` ⇒ 倾角 61°。
此时竖直推力分量只剩 0.48 ⇒ 必然掉高。工程含义：**`COS_MIN=0.5` 对这台机偏松**，下一轮建议 0.7（45°）就切。

### 5.2 两点配平标定的推导

施加 `uA = r·uB`（总推力不变），俯仰力矩 `τ_x = b_f·F_f − b_r·F_r` 对 r **线性**：

```
alpha(r) = C·(b_f·r − b_r)        (A 为前喷口)
alpha(r) = C·(b_f − b_r·r)        (A 为后喷口)
```

两点 `r=1.00`、`r=0.90` 的交点：

```
r* = r1 − alpha1·(r1−r2)/(alpha1−alpha2)
```

实测 `alpha(1.00)=−0.132`、`alpha(0.90)=+0.169` ⇒ **r\* = 0.9562 < 1 ⇒ A(ch0) 是前喷口**（几何先验 0.9512，差 0.5%）。
`r*>1` 则表示 A 是后喷口——判据与配平值一次给出，不需要额外实验。

### 5.3 三轴权限与惯量

脉冲段是三段式（`+1×T`、`−1×2T`、`+1×T`），第一段的速率变化给出权限，第二/三段把角速度送回起点。

| 通道 | 激励 | 实测权限 | 反推惯量 |
|---|---|---|---|
| 差动推力 → 俯仰 | `±0.02`（每台） | **α/D = −31.7 rad/s²/单位** | I_pitch = K·p·4.00/31.7 ≈ **65 kg·m²** |
| 同向锥角 → 滚转 | `±0.40`（15° 的 27%） | **+2.0~3.5 rad/s²/单位** | I_roll ≈ **21** |
| 反向锥角 → 偏航 | `±0.15`（CAL） | **+1.5 rad/s²/单位** | — |
| Z 锥角 → 俯仰 | `±0.40` | **+0.8 rad/s²/单位** | 与 I_pitch 同阶，自洽 |

**注意三个 α/D 读数不一致**：长窗 0.5 s 得 −31.7、CAL 0.3 s 得 −47.7、CAL 0.4 s 得 −16.2。
短窗包含喷口 0.2 s 出力渐变的暂态，读数随窗口长度摆动；**环内只用「同一段自洽增益」**（稳定），
但要做精确惯量必须用 ≥1 s 的干净窗。此项列入待查。

### 5.4 欧拉角 ↔ 体轴符号（反直觉，必须记住）

- `d(pitch)/dt = −ωx`：BRAKE 段 `pitch` 从 −0.59° 降到 −3.9°（−1.6°/s），而 `wx` 一直是 **+0.02~+0.04 rad/s**。
- `d(roll)/dt = +ωz`：XTLTP 段 `roll` 从 −0.03° 升到 1.34°，`wz` 从 0.0037 升到 0.2544。
- `d(yaw)/dt = +ωy`（由 CAL 的 `sY=+1` 反推）。

所以姿态环**不能复用任何「pitch 与 wx 同号」的直觉**；`m2hover` 的做法是每个轴先测 `s` 再用
`u = −(kp·θ + kd·s·ω + ki·I)/(s·g)`。
